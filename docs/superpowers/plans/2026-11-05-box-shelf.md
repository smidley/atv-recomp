# Box Shelf Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show every game in Nativecade's library as a 3D Nintendo 64 box on a shelf, facing out or spines out, and open a picked box to its cartridge before the game starts.

**Architecture:** The logic lives in the RecompSources package with Swift Testing tests: RomM's box art fields, which faces are real or drawn, the shelf layout, the inspect state machine and frame-time summaries. The app renders with RealityKit on tvOS 26: one focusable `RealityView` per shelf row, and a full-screen inspect view presented over the library. Faces RomM doesn't have are drawn once with SwiftUI's `ImageRenderer` and cached.

**Tech Stack:** Swift 6, SwiftUI, RealityKit (tvOS 26), Swift Testing, the RomM 5.4.1 API.

**Spec:** [docs/superpowers/specs/2026-11-05-box-shelf-design.md](../specs/2026-11-05-box-shelf-design.md). The mockups beside it are the visual reference.

## Global Constraints

- Every `TVOS_DEPLOYMENT_TARGET` in `RecompTV.xcodeproj/project.pbxproj` becomes `26.0` (three lines, `17.0` today). `Packages/RecompSources/Package.swift` keeps `.tvOS(.v17)`: the package uses no RealityKit.
- All 3D is RealityKit. No SceneKit, and no boxes faked with SwiftUI's `rotation3DEffect`.
- One easing curve: `.cubicBezier(controlPoint1: [0.22, 1], controlPoint2: [0.36, 1])` in RealityKit, `.timingCurve(0.22, 1, 0.36, 1, duration:)` in SwiftUI.
- Art comes only from RomM, through `LibraryModel.artworkData(at:artwork:sourceID:)`. Never call LaunchBox or ScreenScraper, and never change RomM's settings or start its scans.
- Drawn art writes the platform as plain text, "Nintendo 64": no Nintendo logos or box designs. No Boxshelf code, assets or models.
- Copy: sentence case, no period on short strings. The new strings are "Shelf view", "Facing you", "Spines out", "Favorites", "Swipe to turn it · Select opens it", "Select plays · Back puts it away", "Add to Favorites", "Remove from Favorites".
- Setup and Settings keep their look; Settings gains only the Shelf view choice.
- No ROM data in builds. Fixture code stays behind `#if DEBUG && targetEnvironment(simulator)`, like `SyntheticLibrary`.
- Register each new app Swift file: `python3 scripts/add-swift-files-to-project.py RecompTV.xcodeproj/project.pbxproj RecompTV/Library/<File>.swift` (Task 1 adds the script).
- Package tests: `bash scripts/test-network-sources.sh` must pass. The network tests also need `RECOMPTV_NETWORK_FIXTURES=1` and the fixture server (`build/fixtures-venv/bin/python scripts/network-fixtures.py`). App build: `bash scripts/ci-build-tvos.sh simulator` ends with `** BUILD SUCCEEDED **`.
- Screenshots: `python3 scripts/run-source-simulator-probe.py --app build/simulator/Build/Products/Debug-appletvsimulator/RecompTV.app --output build/box-shelf-screens --screens <steps>`, with the fixture server running.
- Commits use the repo's local identity and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never commit `audit.log`, `.superpowers/` or `.impeccable/`.
- Hardware testing happens only in a TestFlight build the owner approves. The simulator checks the look, not the speed.
- Every supported platform today is Nintendo 64, so every box holds a cartridge. The spec's disc model waits for the first disc-based platform and isn't part of this plan.

## Review Focus

1. **A game with no RomM art at all** (an SMB import, or every synthetic game) shows a complete box: title-art front, drawn spine, back and label, never a blank face. Task 2 `facesAreDrawnWithoutArtwork`; Task 5 draws them; Task 7 screenshot.
2. **A game with only some faces in RomM** (cover and spine, no back) mixes real and drawn faces. Task 2 `mixesRemoteAndDrawnFaces`.
3. **Art that fails to download** (offline, connection removed) falls back to drawn faces instead of an empty or forever-loading box. Task 5: `BoxArtLoader` treats a `nil` from `artworkData` as drawn; the synthetic games prove it in Task 7's screenshot.
4. **Rapid presses:** Select twice on an open cartridge starts the game once, and Back while it starts does nothing. Task 3 `selectStartsTheGameOnce`, `ignoresInputWhileStarting`.
5. **Edge-sized shelves and long titles:** a one-game shelf ignores left and right, an empty one draws nothing, and 60-character titles wrap to two lines and then truncate. Task 4 `oneBoxShelfIgnoresMoves`, `emptyShelfDrawsNothing`; Task 5's long synthetic titles, seen in Task 7's screenshot.

```python
"""Register Swift files in RecompTV.xcodeproj the way LibraryView.swift is registered."""
import pathlib
import sys
import uuid

project = pathlib.Path(sys.argv[1])
text = project.read_text()
ANCHOR = '"370340BBE638A857F7D98094" = { "isa" = "PBXBuildFile"; "fileRef" = "042064B99A910D4E9735395E"; };\n'
CHILD = '\t\t\t\t"042064B99A910D4E9735395E",\n'
PHASE = '\t\t\t\t"370340BBE638A857F7D98094",\n'
assert text.count(ANCHOR) == 1 and text.count(CHILD) == 1 and text.count(PHASE) == 2, "project layout changed"


def new_id():
    while True:
        candidate = uuid.uuid4().hex[:24].upper()
        if candidate not in text:
            return candidate


for path in sys.argv[2:]:
    if f'"path" = "{path}"' in text:
        print("already registered:", path)
        continue
    ref, build = new_id(), new_id()
    text = text.replace(ANCHOR, ANCHOR
        + f'\t\t"{ref}" = {{ "isa" = "PBXFileReference"; "lastKnownFileType" = "sourcecode.swift"; "path" = "{path}"; "sourceTree" = "SOURCE_ROOT"; }};\n'
        + f'\t\t"{build}" = {{ "isa" = "PBXBuildFile"; "fileRef" = "{ref}"; }};\n')
    text = text.replace(CHILD, CHILD + f'\t\t\t\t"{ref}",\n')
    text = text.replace(PHASE, PHASE + f'\t\t\t\t"{build}",\n')
    print("registered:", path, ref, build)
project.write_text(text)
```

### Task 3: The inspect state machine

**Files:**
- Create: `Packages/RecompSources/Sources/RecompSources/BoxInspection.swift`
- Create: `Packages/RecompSources/Tests/RecompSourcesTests/BoxInspectionTests.swift`

**Interfaces:**
- Produces:

```swift
public enum RemoteInput: Sendable { case left, right, up, down, select, back }
public enum BoxSide: Sendable { case front, right, back, left }
public struct BoxInspection: Equatable, Sendable {
    public enum Stage: Equatable, Sendable { case looking, open, starting }
    public enum Effect: Equatable, Sendable { case play, dismiss }
    public private(set) var stage: Stage          // starts .looking
    public private(set) var quarterTurns: Int     // starts 0; right adds 1, left subtracts 1
    public var side: BoxSide { get }              // quarterTurns mod 4: front, right, back, left
    public init()
    public mutating func handle(_ input: RemoteInput) -> Effect?
}
```

Transitions:
- **Looking:** left and right turn the box. Select opens it, rounding `quarterTurns` to the nearest multiple of 4 (halves away from zero) so it opens facing front. Back returns `.dismiss`.
- **Open:** Select moves to starting and returns `.play`. Back returns to looking.
- **Starting:** ignores everything.
- **Up and down:** always return `nil`, without changing anything.

### Task 4: Shelf style and layout

**Files:**

```swift
public enum ShelfStyle: String, Codable, CaseIterable, Sendable {
    case facing, spines
    public var title: String { get }       // "Facing you", "Spines out"
    public var wallRowLength: Int { get }  // games per shelf on a platform's page: 8 facing, 24 spines
}
public enum ShelfMetrics {
    public static let box = SIMD3<Float>(0.17, 0.124, 0.034)        // width, height, depth
    public static let cartridge = SIMD3<Float>(0.106, 0.069, 0.015)
    public static let facingPitch: Float = 0.195
    public static let spinePitch: Float = 0.0375
    public static let spineParting: Float = 0.07
}
public struct BoxPlacement: Equatable, Sendable {
    public var x: Float, lift: Float, forward: Float
    public var yaw: Float            // radians: 0 faces the viewer, .pi / 2 shows the spine
    public var cartridgeRise: Float  // how far the cartridge stands up out of the box
}
public struct ShelfLayout: Equatable, Sendable {
    public init(count: Int, style: ShelfStyle, focus: Int, viewportWidth: Float, raised: Bool = true)
    public let count: Int, style: ShelfStyle, focus: Int  // focus clamped to 0..<max(count, 1)
    public func placement(of index: Int) -> BoxPlacement
    public var scroll: Float { get }        // max(0, focus x − 0.3 × viewportWidth)
    public var visible: Range<Int> { get }  // indices with x − scroll in [−pitch, viewportWidth + pitch]
    public func moved(_ input: RemoteInput) -> ShelfLayout  // left and right move the focus, clamped
    public static func rows<T>(_ items: [T], style: ShelfStyle) -> [[T]]  // chunks of style.wallRowLength
}
```

Placement values:
- **Facing:** `x = index × facingPitch`, yaw 0. The focused box, when `raised`, has lift 0.012, forward 0.045 and `cartridgeRise = box.y − 0.32 × cartridge.y − 0.005`. Every other box has zeros.
- **Spines:** `x = index × spinePitch`, yaw `.pi / 2`. When `raised`, boxes before the focus move by `−spineParting` and boxes after it by `+spineParting`. The focused box gets lift 0.012, forward 0.06, yaw 0.314 (18 degrees) and the same cartridge rise.
- **Not raised:** no box is raised and nothing parts. A shelf without focus uses this.

  - **Front, 340 × 248,** when there is no cover: `TitleArt`.

### Task 6: The 3D box, cartridge and shelf

**Files:**
- Create: `RecompTV/Library/BoxEntities.swift`
- Modify: `RecompTV/Library/LibraryView.swift` (`SetupFixturePreview`: step `box-faces`)
- Modify: `scripts/run-source-simulator-probe.py` (`SETUP_STEPS` gains `box-faces`)

**Interfaces:**
- Consumes: `BoxArt` (Task 5), `ShelfMetrics` (Task 4).
- Produces:

```swift
@MainActor enum BoxEntities {
    static func box(_ art: BoxArt) throws -> ModelEntity    // with the cartridge as child "cartridge", sitting inside
    static func cartridge(label: CGImage) throws -> Entity
    static func shelf(width: Float) -> ModelEntity
    static func lights() -> Entity
}
```

Construction:
- **Box:** `MeshResource.generateBox(width: box.x, height: box.y, depth: box.z, cornerRadius: 0.002, splitFaces: true)` with six `PhysicallyBasedMaterial`s. ```
